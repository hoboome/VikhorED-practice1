# vshell — эмулятор командной оболочки UNIX

Практическая работа №1 «Конфигурационное управление», вариант 6.
Студент: Вихорь Елена Даниловна.

Этап 1: окно-терминал на tkinter, разбор ввода по пробелам, заглушки `ls`
и `cd`, команда `exit`. Запуск — `./run.sh`, тесты — `make test`.

Этап 2: параметры `-v/--vfs`, `-s/--script`, `-c/--console`, отладочный
вывод параметров, стартовый скрипт (ошибочные строки пропускаются),
скрипт ОС `os_scripts/check_args.sh`.
